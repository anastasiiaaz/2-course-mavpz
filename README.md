# Опис проєкту:

Веб-сервіс для пошуку та придбання квитків на концерти й інші культурні заходи по всій Україні. Платформа дозволяє переглядати актуальну афішу подій у різних містах та обирати квитки за категоріями, жанрами, цінами.

Користувачі можуть купувати квитки на події, обирати їх місце та застовувати знижки при оплаті. Є можливість створити акаунти, зберігати улюблені заходи та переглядати схожі події.
