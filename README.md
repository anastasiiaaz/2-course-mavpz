# Опис проєкту:

веб-сервіс для пошуку та придбання квитків на концерти й інші культурні заходи по всій Україні. Платформа дозволяє переглядати актуальну афішу подій у різних містах, обирати квитки за категоріями, жанрами цінами, та зберігати улюблені заходи у персональний акаунт.

# Бізнес-логіка:

- користувачі можуть переглядати події за категоріями/містами/жанрами/датами

- користувачі можуть купувати квитки на події, обирати їх місце та застовувати знижки при оплаті, отримувати квитанцію оплати

- користувачі можуть зберігати улюблені заходи та переглядати схожі події
